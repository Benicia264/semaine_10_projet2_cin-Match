
# 🎬 CinéMatch - Catalogue de Films (TMDB)

**CinéMatch** est une application web dynamique qui permet de parcourir un catalogue de films et d'effectuer des recherches en temps réel en exploitant l'API de TMDB (The Movie Database).



## Fonctionnalités

* **Affichage dynamique :** Récupération et affichage des films sous forme de cartes (affiches, titres).
* **Barre de recherche :** Recherche de films en temps réel via des requêtes API.
* **Interactivité :** Événements au clic sur les éléments pour interagir avec les films.
* **Interface sombre & moderne :** Design épuré inspiré des plateformes de streaming.



## 🛠️ Technologies utilisées

* **HTML5 :** Structure de la page (`index.html`)
* **CSS3** : Styles, mise en page et design responsive
* **JavaScript (ES6+)** : Manipulation du DOM, gestion des événements et appels API (`fetch`)
* **API externe** : [TMDB API](https://www.themoviedb.org/)
